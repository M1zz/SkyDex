プライバシーポリシー

iOS アプリ SkyDex · 2026年8月20日施行

要点です。このアプリにアカウントはありません。写真と色は、お使いの端末とご自身の iCloud にだけ保存され、開発者はどちらも開くことができません。

開発者に届くのは三つだけです。匿名の利用統計、ご自身で送るフィードバック、クラッシュレポート。写真と色は、そのどれにも含まれません。広告も、トラッキングも、外部の分析 SDK もありません。

1. 写真と記録

アプリで撮影した写真やライブラリから選んだ写真、そこから抽出した色、撮影時刻、書き込んだメモは、お使いの端末内のアプリのストレージに保存されます。開発者には送信されず、開発者のサーバーにもアップロードされません。開発者はサーバーを運用していません。

iCloud への保存

端末が Apple アカウントにサインインしている場合、これらの記録はご自身の iCloud（Apple の CloudKit プライベートデータベース）にも保存されます。端末をなくしたり、アプリを削除して入れ直したりしても、集めた空が戻ってくるようにするためです。

  • 保存先はお客様の iCloud アカウントであり、開発者のサーバーではありません。開発者はこのデータを見ることができず、コピーも持っていません。
  • 同じ Apple アカウントでサインインしているご自身の端末の間でのみ移動します。他の人に表示されることはなく、このアプリには共有や投稿の機能自体がありません。
  • アプリ内で記録を削除すると、iCloud 上のコピーも削除されます。
  • これらが使う容量は、お客様の iCloud ストレージの容量に含まれます。
  • iCloud にサインインしていない場合や、設定でこのアプリの iCloud をオフにした場合は、アプリはすべてを端末内に保管し、これまでどおり動作します。

この保存先は Apple のポリシーに従います — Apple プライバシーポリシー。端末をバックアップ（iCloud またはコンピュータ）すると、この保存データがバックアップに含まれることがあります。そのバックアップもお客様の Apple アカウントのものであり、開発者はアクセスできません。

2. 位置情報

位置情報は、次のふたつの目的にだけ使います。

  • お住まいの場所の日の出と日の入りを求め、ボードの基準となる空の色が正しい時刻に来るようにする
  • お住まいの場所の今日の1時間ごとの予報（雲と雨）を取得する

求める精度はキロメートル単位だけです。最後の座標は端末に保存され、写真に付与されることも、開発者に送信されることもありません。

予報を取得するため、この大まかな座標はApple の天気サービス（WeatherKit）に送信されます。この送信は Apple のポリシーに従います — Apple プライバシーポリシー、Apple Weather に関する表示。

位置情報へのアクセスを許可しなくても、アプリは問題なく動作します。その場合は既定の場所（ソウル）で色を計算し、予報なしの快晴を基準に描きます。

3. カメラと写真ライブラリ

カメラは、空を撮影している間だけオンになります。ライブラリからは、選んだ1枚の写真だけを読み取り、残りのライブラリを閲覧することはありません。アプリが写真をライブラリに保存することもありません。

4. 利用統計とフィードバック

アプリを作る人が使われ方をまったく知らなければ、直すべきところを直せません。そのため、受け取るのは次の三つだけです。三つとも開発者の CloudKit パブリックデータベースに届きます。別のサーバーはやはりありません。

匿名の利用統計

  • 送信される内容: アプリを開いた回数、インストールからの日数、アプリのバージョン、iOS のバージョン、端末の種類、言語設定。
  • インストールは端末やアカウントと結びつかないランダムな番号で区別します。アプリを削除して入れ直すと新しい番号になり、他のアプリや広告 ID と関連づけることはできません。
  • 写真、色、撮影時刻、メモ、位置情報は一切送信されません。
  • 個人の特定や追跡には使わず、他の会社に渡すこともありません。

フィードバック

設定 → サポート → フィードバックを送るから、ご自身で送信したときにのみ送られます。書いた内容は、アプリと端末のバージョンとともに届きます。返信用のお名前とメールアドレスは、入力した場合にのみ送信されます。空欄にすれば、まったく記録されません。

クラッシュレポート

アプリがクラッシュしたり固まったりすると、あとから iOS がまとめる診断情報（どこで落ちたか、アプリと iOS のバージョン、端末の種類）が開発者に届きます。インストールの識別子も付きません。

5. 収集しないもの

  • 名前、メールアドレス、電話番号、アカウント — サインインそのものがありません。（唯一の例外は、フィードバックにご自身で入力した返信先です。）
  • 写真、色、撮影時刻、メモ — 第4項のどの情報にも含まれません
  • 位置情報 — 統計にもフィードバックにも付きません
  • 広告 ID、トラッキング、プロファイリング、外部の分析 SDK — 使用しません
  • 収集した情報の他社への販売や提供 — 一切行いません

6. 保存期間と削除

記録は、削除するまで残ります。写真を開いて削除をタップするか、記録で左にスワイプすると、その記録は端末と iCloud から削除されます。

アプリを削除すると、端末内のストレージと座標は消えますが、iCloud 上のコピーは残ります。入れ直したときにコレクションが戻ることが、この機能の目的だからです。完全に消すには、アプリ内で記録を削除するか、iOS の設定 → Apple アカウント → iCloud → ストレージを管理でこのアプリのデータを削除してください。

開発者はコピーを持っていないため、開発者に別途削除を依頼する必要はありません。

7. お子様

このアプリは、お子様を含むどのユーザーからも個人情報を収集しません。

このポリシーを変更する場合は、上記の施行日とともにこのページを更新します。変更の履歴は GitHub のコミット履歴で確認できます。
